# 01 스위스 포스터

단색 바탕 위에 4단 그리드. 위에는 작은 글씨 줄, 가운데는 사진 블록, 아래는 화면을 가로지르는 아주 큰 국문 제목.

## 참고
- 레어로우 [청담 플래그십 리뉴얼 세일](https://www.instagram.com/rareraw_official/p/DeOX9hZunDH/): 색 바탕 + 위 작은 글씨 여러 단 + 왼쪽 아래 아주 큰 국문 제목
- 레어로우 [UNLIMITED-R EDITION](https://www.instagram.com/rareraw_official/p/Dd6C4aIl55-/): 맨 아래 `( ) ( ) ( )` 괄호 태그 줄
- 캡처: `reference/05_포스터_rareraw_a.png`, `reference/05_포스터_rareraw_b.png`

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 바탕 | 팔레트 단색 (게시물마다 다름, `color`) |
| 그리드 | 좌우 여백 40px, 4단, 단 사이 20px |
| 맨 위 줄 | `TERUVA / Wine Cellar / 2026 / No. NN` 4단, Pretendard 600 17px, 위 38px. 아래 1px 선(투명도 50%) |
| 사진 블록 | 745 × 690px, 위 110px. 오른쪽 3단(`side: r`, 왼 295px) 또는 왼쪽 3단(`side: l`, 왼 40px) |
| 빈 단 | 작은 설명 Pretendard 500 19px 줄 간격 1.5, 아래쪽에 빨간 마크 36px |
| 제목 | Pretendard 800, 132px, 줄 간격 1.06, 자간 -0.045em, 2줄, 왼 34px · 아래 122px |
| 맨 아래 | 1px 선 + 왼쪽 영문 부제 / 오른쪽 `(TERUVA) (WINE AT HOME) (2026)`, Pretendard 500 19px |
| 글자색 | 어두운 바탕은 #F4F0E8, 밝은 바탕은 #1C1B19 |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
