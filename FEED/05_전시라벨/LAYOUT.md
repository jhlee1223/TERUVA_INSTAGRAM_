# 05 전시 라벨

벽에 걸린 액자 사진 + 오른쪽 전시 제목·설명 + 작품 라벨. 아래에 바닥 띠.

## 참고
- 레어로우 [CURATED ECLECTICISM / whynot reinterpreting 전시](https://www.instagram.com/rareraw_official/p/DeeA2W4F3KI/): 벽의 소문자 굵은 전시 제목 + 이탤릭 + 작은 설명
- 캡처: `reference/_rareraw_최근24.jpg` (첫 줄 세 번째)

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 벽 / 바닥 | 벽 #EBE6DC, 아래 120px 바닥 #DED7CB, 경계 1px 선 |
| 액자 | 사진 640 × 800, 흰 매트 22px(#FBFAF7), 그림자 0 26px 50px 검정 16%, 왼 66 · 위 150px |
| 전시 제목 | 오른쪽 단(왼 780, 폭 250px): `teruva at home` Pretendard 700 34px + `a still life with wine` Instrument Serif 이탤릭 34px |
| 전시 설명 | 국문 Pretendard 18px 줄 간격 1.65 + 영문 16px |
| 작품 라벨 | 위 806px: `No. NN` 14px + 작품명 Noto Serif KR 30px + 영문 Instrument Serif 이탤릭 25px + `TERUVA, 2026 / 와인 냉장고, 생활 공간` 14px |
| 마크·로고 | 빨간 마크 40px(위 1150px), 컬러 로고 140px(오른쪽 아래) |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
