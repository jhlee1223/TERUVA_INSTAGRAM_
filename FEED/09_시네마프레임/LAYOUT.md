# 09 시네마 프레임 (릴스)

세로 영상의 위아래를 검정 띠로 덮어 영화 화면처럼 만들고, 띠 안에 세리프 제목과 자막을 넣는다. 화면 네 모서리에 촬영 프레임 표시.

## 참고
- 레어로우 릴스의 국·영 자막 (https://www.instagram.com/rareraw_official/reel/DeMDu3rhaL3/)
- 영화 레터박스·뷰파인더 형식

## 규격 (1080 × 1920, 30fps, 소리 없음)
| 요소 | 값 |
|---|---|
| 띠 | 위 0~330px, 아래 1590~1920px, #121211 (영상 내내) |
| 맨 위 줄 | `TERUVA FILM` / `No. NN — 2026`, Pretendard 700 15px 자간 0.3em, 위 66px |
| 제목 | Instrument Serif 이탤릭 84px, 가운데, 위 146px |
| 모서리 표시 | 화면 영역 네 모서리에 L자 44px, 3px 흰색 85% |
| 자막 | 위 1650px: 국문 Pretendard 500 32px + 영문 Instrument Serif 이탤릭 34px |
| 맨 아래 | `TERUVA.IO` 15px 자간 0.3em, 위 1836px |
| 커버 | `cover.jpg` = 1.5초 장면 |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
