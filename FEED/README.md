## 게시물 폴더
`<디자인>/<번호>/` 안에:
- `post.jpg` — 올릴 이미지 (1080 × 1350, 4:5)
- `post.mp4` + `cover.jpg` — 릴스 (1080 × 1920, 9:16). 올릴 때 커버로 `cover.jpg`를 고른다. **소리가 없으니 인스타 앱에서 음악을 붙인다**
- `caption.txt` — 캡션 (제품 소개 3~5줄 + 고정 문구·해시태그·URL, 그대로 붙여 넣기). 규칙은 `../caption.md`, 원문은 `../CAPTIONS.md`

## 규칙
- 한 디자인 안에서는 같은 사진·영상을 두 번 쓰지 않는다 (`make_feed.py`가 만들기 전에 검사한다). 디자인이 다르면 같은 사진을 다시 쓸 수 있다
- 사진 소스: `Pic&Videos/모델촬영_셀렉` 39장 / 영상 소스: `Pic&Videos/영상` 19개 (세로 4K)
- 문구는 사진·영상에 실제로 보이는 것만 쓴다. 용량·온도·소음·가격 같은 사양은 근거 자료가 생기면 추가한다
- 다이어그램의 숫자는 장난스러운 표현이고 실제 통계가 아니다

## 다시 만들기
```
python make_feed.py                  # 100개 전부 (릴스 때문에 15분 정도)
python make_feed.py 07_마크창         # 한 디자인만
python make_feed.py --captions       # CAPTIONS.md를 고친 뒤 caption.txt만 다시 쓰기 (몇 초)
```
사진 선택·자르는 위치·이미지 속 문구는 `feed_posts.py`, 캡션은 `CAPTIONS.md`, 디자인은 `make_feed.py`에서 고친다.
