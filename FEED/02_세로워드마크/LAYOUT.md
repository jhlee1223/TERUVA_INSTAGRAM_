# 02 세로 워드마크

사진 왼쪽 가장자리를 따라 TERUVA 로고를 화면 높이만큼 세로로 세운다. 로고가 사진 일부를 덮는 것이 디자인의 핵심.

## 참고
- 레어로우 [RARERAW EDITION OPEN D-5](https://www.instagram.com/rareraw_official/p/Dd6T9D4l_X4/): 사진 위에 브랜드 워드마크를 크게
- 애플 홈페이지 iPhone 18 Pro: 화면을 가득 채운 거대한 `PRO` 글자 (`reference/08_타일_apple_홈페이지.jpg`)

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 사진 | 꽉 채움. 사람이 로고에 가리지 않게 `zoom`·`fx`로 오른쪽으로 당김 |
| 로고 | 흰색 로고(마크 포함), 길이 1270px(두께 약 126px), -90도 회전(아래→위로 읽힘), 왼 42px · 위 40px |
| 그림자 | 왼쪽 30%까지 검정 30%→0, 아래 42%에 검정 0→38% |
| 오른쪽 위 | `No. NN / WINE AT HOME`, Pretendard 600 17px, 오른쪽 정렬 |
| 오른쪽 아래 | 국문 Pretendard 700 46px 줄 간격 1.25 + 14px 아래 영문 500 20px, 오른쪽 48 · 아래 56px |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
