# 03 컬러 블록

왼쪽 440px은 색 면, 오른쪽 640px은 사진. 색 면에 큰 번호와 글을 세로로 쌓고, 두 면의 경계에 빨간 마크를 걸친다.

## 참고
- MMK·로코의 색 대비 (`reference/_mmk_최근24.jpg`, `reference/_rocco_최근24.jpg`)
- 레어로우 포스터의 숫자·선 그리드

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 색 면 | 왼쪽 0~440px, 팔레트 단색 |
| 사진 | 640 × 1350, 왼 440px |
| 번호 | Archivo 폭 125% · 800, 170px, 왼 40 · 위 30px |
| 선 | 2px, 폭 352px, 위 236px |
| 제목 | Pretendard 700, 50px, 줄 간격 1.24, 자간 -0.035em, 위 278px |
| 본문 | 30px 아래, Pretendard 400 21px 줄 간격 1.7, 투명도 85% |
| 영문 | 28px 아래, Pretendard 700 15px 자간 0.16em |
| 아래 | `teruva.io` 16px(아래 108px) + 로고 170px(아래 58px) |
| 경계 마크 | 빨간 마크 96px, 왼 392 · 위 1150px (빨강 바탕일 때는 아이보리) |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
