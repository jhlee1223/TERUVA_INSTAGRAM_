# 04 매거진 커버

인물 사진 위에 세리프 제호 `Wine at Home`, 왼쪽 커버 문구 2개, 왼쪽 아래 커버 스토리.

## 참고
- 로코 [WWD 기사 카드](https://www.instagram.com/roccofridge/p/DeKVJ_dtteQ/): 잡지·기사 형식 (`reference/_rocco_최근24.jpg`)
- 샤넬 홈페이지의 인물 사진 + 글 (`reference/07_히어로_chanel_홈페이지.jpg`)

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 사진 | 꽉 채움 + 위 32%·아래 48%에 검정 그라데이션(40%·45%) |
| 맨 위 | `TERUVA JOURNAL · No. NN · OCTOBER 2026`, Pretendard 600 15px 자간 0.28em, 위 40px |
| 제호 | Instrument Serif 178px, 자간 -0.015em, 가운데, 위 62px |
| 커버 문구 | 왼 52 · 위 330px, 라벨 Pretendard 700 14px 자간 0.2em + 본문 600 30px, 덩어리 사이 34px |
| 커버 스토리 | `COVER STORY` 14px + Pretendard 800 88px 줄 간격 1.1 자간 -0.04em, 왼 52 · 아래 118px, 아래 흰 선 120px |
| 로고 | 흰색 150px, 오른쪽 52 · 아래 70px |

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
