# 06 디테일 주석

제품이 잘 보이는 사진 위에 점과 선으로 부위를 짚고, 흰 박스 라벨에 영문·국문 이름을 단다.

## 참고
- 애플 제품 페이지의 부위 설명 방식 (`reference/08_타일_apple_홈페이지.jpg`)
- 레어로우 기능 박스(흰 바탕 + 검정 테두리 + 굵은 글씨) (`reference/06_기능박스_rareraw_a.png`)

## 규격 (1080 × 1350)
| 요소 | 값 |
|---|---|
| 사진 | 꽉 채움 + 검정 8% + 위 26%에 검정 그라데이션 (흰 배경 사진은 생략) |
| 점 | 지름 18px 원 + 지름 40px 테두리 원(1.5px, 75%) |
| 선 | 2px, 점 → 라벨 |
| 라벨 | 흰 바탕, 2px 검정 테두리, 여백 9·14·10px. 영문 Pretendard 700 13px 자간 0.16em + 국문 700 24px |
| 제목 | `Details` Instrument Serif 이탤릭 76px + `No. NN` 18px + 부제 Pretendard 600 24px, 왼 52 · 위 42px |
| 흰 배경 사진 (`ink`) | 01·02번: 선·점·제목을 검정으로, 로고는 컬러 |
| 점 위치 | `feed_posts.py`의 `points` (화면 좌표, 사진에 눈금을 그려 측정) |

## 짚는 부위
상판 TOP · 유리문 GLASS DOOR · 손잡이 HANDLE · 선반 SHELVES · 디스플레이 DISPLAY · 로고 LOGO · 와인 선반 RACK · 다리 LEGS — 사진에 보이는 것만

## 공통
- 색: 아이보리 #EFEAE1 · 페이퍼 #F6F3ED · 버터 #E7DCC3 · 잉크 #1C1B19 · 슬레이트 #6E7D89(냉장고 문틀) · 테라코타 #A65A42(바닥 타일) · 오크 #A97C4F · 올리브 #76745A · 레드 #DE4A37(로고)
- 글꼴: Pretendard(국·영 본문), Archivo 넓은 폭(숫자·제목), Instrument Serif(영문 세리프), Noto Serif KR(국문 명조)
- 로고 마크: 로고의 빨간 도형을 벡터로 다시 그린 것(`make_feed.py`의 `MARK_D`)

## 캡션
`caption.md` 규칙: 제품 소개 3~5줄(완성된 문장) + 고정 문구. 감도 높은 형용사·부사 2문장 이상, 날씨·경험·모델의 행동·시간대를 녹인다. 캡션 원문은 `CAPTIONS.md`.
