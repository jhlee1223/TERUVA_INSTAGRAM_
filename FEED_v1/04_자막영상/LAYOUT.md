# 04 자막 영상 (릴스)

세로 영상 아래쪽에 국문·영문 자막 한 쌍. 영상 절반마다 자막이 바뀐다 (2개).

## 참고한 레퍼런스
- 레어로우 릴스 [시스템000 디테일 - 자석형 조명 유닛](https://www.instagram.com/rareraw_official/reel/DeMDu3rhaL3/): 아래쪽에 작은 국문 + 영문 자막
- 로코 프리지(@roccofridge) 릴스 [The top doubles as a workstation…](https://www.instagram.com/roccofridge/reel/Ddocr88BSTf/): 짧은 영어 한 줄, 위트 있는 말투
- 캡처: `reference/04_자막_rareraw_a.png`, `reference/04_자막_rocco_b.png`

## 규격
| 항목 | 값 |
|---|---|
| 영상 | 03과 같음 (1080 × 1920, 30fps, 소리 없음, 7.5~8초) |
| 국문 자막 | Pretendard 600, 36px, 줄 간격 1.45, 흰색 |
| 영문 자막 | 국문 18px 아래, Pretendard 600, 31px, 줄 간격 1.35, 흰색 |
| 위치 | 가운데 정렬, 자막 덩어리 위쪽이 화면 66%(y ≈ 1267px), 좌우 여백 70px |
| 그림자 | 글자: 0 1px 12px 검정 45% / 화면: 영상 내내 아래쪽 옅은 그림자 (48% 지점 0 → 70% 28% → 끝 36%) |
| 시간 | 첫 자막 0.3초 ~ 절반, 둘째 자막 절반+0.1초 ~ 끝-0.1초, 각각 0.5초씩 나타나고 사라짐 |
| 커버 | `cover.jpg` = 1.5초 장면 + 첫 자막 |

## 코멘트 형식 (로코 방식, 2줄)
1. 위트 있는 영어 한 문장
2. 국문 풀이
