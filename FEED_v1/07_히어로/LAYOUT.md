사진을 꽉 채우고 가운데 아래에 작은 분류 → 넓고 굵은 대문자 제목 → 작은 흰 버튼을 쌓는다.

## 참고한 레퍼런스
- 샤넬 코리아 홈페이지 메인 (https://www.chanel.com/kr/): 큰 사진마다 가운데 아래에 `향수` → `코코 마드모아젤 크러쉬 압솔뤼` → `[자세히 보기]` 흰 버튼
- 캡처: `reference/07_히어로_chanel_홈페이지.jpg` (2026-10-18)

## 규격
| 항목 | 값 |
|---|---|
| 크기 | 1080 × 1350, 사진 꽉 채움 + 아래 45%에 검정 그라데이션(0 → 22%) |
| 글자 덩어리 | 가운데 정렬, 위쪽이 화면 71%(y ≈ 958px), 그림자 0 0 24px 검정 20% |
| 분류 | Pretendard 700, 18px, 흰색 (예: `다이닝`) |
| 제목 | 분류 12px 아래, Archivo 폭 125%(넓은 글꼴 — TERUVA 로고와 같은 넓은 비율), 600, 48px, 자간 0.02em, 흰색 대문자 |
| 버튼 | 제목 30px 아래, 흰 바탕 검정 글자 `teruva.io`, Pretendard 700, 16px, 여백 14 · 30px |
