# 03 센터 타이틀 영상 (릴스)

세로 영상 가운데에 좁고 굵은 영문 대문자 제목 2줄, 아래에 작은 국문 한 줄. 제목은 처음 4초만 보이고 이후는 영상만 흐른다.

## 참고한 레퍼런스
- 레어로우(@rareraw_official) 릴스: [RARERAW EDITION — PRE-OPEN SKETCH](https://www.instagram.com/rareraw_official/reel/DeglsPhkhAG/), [SYSTEM000 DETAILS](https://www.instagram.com/rareraw_official/reel/DeMDu3rhaL3/)
- 캡처: `reference/03_센터타이틀_rareraw_a.png`, `reference/_rareraw_최근24.jpg`

## 규격
| 항목 | 값 |
|---|---|
| 영상 | 1080 × 1920 (9:16), 30fps, H.264, 6.5~8초, **소리 없음** (인스타 앱에서 음악을 붙인다) |
| 원본 | `Pic&Videos/영상`의 세로 4K 영상을 자르지 않고 그대로 줄임 |
| 제목 | Oswald 500, 100px, 줄 간격 1.04, 자간 0.01em, 흰색 대문자 2줄, 가운데, 세로 중심 47%(y ≈ 900px), 그림자 0 2px 30px 검정 30% |
| 부제 | Pretendard 600, 32px, 흰색, 가운데, 위에서 66%(y ≈ 1267px) |
| 배경 어둡게 | 제목이 떠 있는 동안만 가운데 타원(가로 80%·세로 42%)을 검정 34%로 — 밝은 벽 위에서도 읽히도록 |
| 시간 | 0.3초부터 0.5초 동안 나타남 → 3.7초부터 사라져 4.2초에 끝 |
| 커버 | `cover.jpg` = 1.5초 장면 + 제목. 피드 격자에서는 가운데만 보이므로 글자를 가운데에 둔다 |

## 코멘트 형식 (레어로우 방식, 3줄)
1. `ENGLISH TITLE — 국문`
2. 국문 한 문장
3. 영문 한 문장
