## 게시물 폴더
`<레이아웃>/<번호>/` 안에:
- `post.jpg` — 올릴 이미지 (1080 × 1350, 4:5)
- `post.mp4` + `cover.jpg` — 릴스 (1080 × 1920, 9:16). 올릴 때 커버로 `cover.jpg`를 고른다. **소리가 없으니 인스타 앱에서 음악을 붙인다**
- `caption.txt` — 코멘트 (3줄 이하, 그대로 붙여 넣기)

## 레퍼런스를 어떻게 봤나 (2026-10-18)
- 인스타그램 3개 채널(레어로우·로코 프리지·MMK): 로그인한 브라우저로 최근 게시물 24개씩, 총 72개의 이미지와 코멘트를 확인
- 샤넬·애플 홈페이지: 실제 브라우저 창으로 열어 끝까지 스크롤하며 캡처
- 캡처와 코멘트 원문은 `reference/`에 있다 (다른 회사 자료라 git에는 올리지 않음)

## 레퍼런스에서 가져온 원칙
- **글은 적게, 사진이 주인공.** 세 채널 모두 글자 없는 사진이 대부분이고, 글이 있어도 2줄 안팎
- **글자는 흰색 산세리프 한 가지.** 박스·그라데이션 장식 없이 사진 위에 바로. 기능 설명만 흰 박스(레어로우)
- **영상은 세로.** 제목은 가운데에 좁고 굵은 대문자, 자막은 아래쪽 작은 국·영 두 줄(레어로우)
- **코멘트:** 레어로우는 짧은 제목 문장 → 설명 → 영문, MMK는 굵은 영문 제목 + `: 국문 부제`, 로코는 위트 있는 영어 한 줄. **해시태그는 거의 쓰지 않는다**

## 공통 규칙
- 사진 소스: `Pic&Videos/모델촬영_셀렉` 39장만 쓴다. 60개 사진 게시물에 나눠 쓰느라 한 장을 최대 2번(서로 다른 레이아웃에서) 쓴다
- 영상 소스: `Pic&Videos/영상` 19개 (세로 4K)
- 글꼴(`fonts/`, 모두 무료 상업 사용 가능한 OFL 라이선스): Pretendard(국·영 본문), Oswald(릴스 제목), Archivo 넓은 폭(히어로 제목)
- 로고: `Logo/TERUVA로고.png`를 흰색 단색으로 바꿔 사진 위에 쓴다
- 문구는 사진·영상에 실제로 보이는 것만 쓴다. 용량·온도·소음·가격 같은 사양은 근거 자료가 생기면 추가한다

## 다시 만들기
```
python make_feed.py              # 80개 전부 (영상 때문에 15분 정도)
python make_feed.py 05_포스터     # 한 레이아웃만
```
사진 선택·자르는 위치·문구는 `feed_posts.py`, 레이아웃 디자인은 `make_feed.py`에서 고친다.
