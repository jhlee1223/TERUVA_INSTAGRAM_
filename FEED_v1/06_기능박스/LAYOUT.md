# 06 기능 박스

사진 위 작은 흰 박스 안에 제품 기능을 국문 2줄 + 영문 2줄로 설명한다.

## 참고한 레퍼런스
- 레어로우 [커스템 X 레어로우 트롤리 TV](https://www.instagram.com/rareraw_official/p/DeJaciPl-8q/): 왼쪽 아래 흰 박스 `캐스터로 부드럽게 이동하고… / Move smoothly with the casters…`
- 레어로우 [ABOUT RARERAW WORK](https://www.instagram.com/rareraw_official/p/DdbLCC4lxer/): 위쪽 흰 박스
- 캡처: `reference/06_기능박스_rareraw_a.png`, `reference/06_기능박스_rareraw_b.png`

## 규격
| 항목 | 값 |
|---|---|
| 크기 | 1080 × 1350, 사진 꽉 채움 |
| 박스 | 흰 바탕, 2px 검정 테두리, 안쪽 여백 위 14 · 좌우 20 · 아래 16px, 최대 폭 600px |
| 박스 위치 | 왼쪽 아래(왼 48, 아래 64px) 또는 왼쪽 위(왼 48, 위 64px) — 설명하는 부분을 가리지 않는 쪽 |
| 국문 | Pretendard 700, 23px, 줄 간격 1.4, 자간 -0.015em, #111, 2줄 |
| 영문 | 국문 6px 아래, Pretendard 700, 21px, 줄 간격 1.3, #111, 2줄 |

## 문구 규칙
- 사진에 실제로 보이는 것만 설명한다 (상판, 손잡이, 선반, 디스플레이, 유리문, 문 열림)
- 용량·온도·소음·전력 같은 수치는 근거 자료가 생기기 전까지 쓰지 않는다

## 코멘트 형식 (레어로우 방식, 3줄)
1. 국문 제목 문장
2. 국문 설명 한 문장
3. 영문 한 문장
